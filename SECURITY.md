Security Policy
Supported Versions

The following versions of this project are currently receiving security updates:

Version	Supported
Latest (main)	✅
Development (dev)	⚠️ Limited
Older Releases	❌

Only the latest production branch (main) is fully supported for security updates.

Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please report it responsibly.

How to Report

Please DO NOT open a public GitHub issue for security vulnerabilities.

Instead, report privately using one of the following methods:

📧 Email: security@yourdomain.com

📧 Admin Contact: support@yourdomain.com

Or use GitHub’s Private Security Advisory feature (if enabled)

What to Include

When reporting a vulnerability, please include:

Description of the issue

Steps to reproduce (if applicable)

Affected components or endpoints

Potential impact (data exposure, auth bypass, etc.)

Screenshots, logs, or proof-of-concept (if available)

Our Response Process

Once a report is received:

We will acknowledge receipt within 24–72 hours

We will investigate and validate the issue

If confirmed, we will:

Develop and test a fix

Release a security patch

Credit the reporter (if requested)

If declined, we will provide a reasoned explanation

Data Protection & Privacy

This project may handle sensitive customer data, including:

Names

Phone numbers

Email addresses

Billing and payment records

We follow best practices to:

Encrypt sensitive data in transit

Restrict admin access

Log and monitor critical actions

Regularly review dependencies for vulnerabilities

Payment & Financial Security

For online payments, we use trusted third-party payment gateways.

We do not store raw card or sensitive payment credentials

All payment processing is handled by compliant payment providers

Payment status updates are validated server-side

Responsible Disclosure

We support responsible disclosure and ask that:

Vulnerabilities are not publicly disclosed until fixed

Researchers give us reasonable time to patch issues

No customer data is accessed, modified, or misused during testing

Security Updates

Security fixes are released as part of regular updates and hotfixes when required.

Users are encouraged to always use the latest version of the software.
